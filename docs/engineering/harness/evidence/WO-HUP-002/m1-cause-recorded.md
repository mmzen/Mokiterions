# M1 - the cause is recorded where the next adoption will meet it

The assurance owner confirms that the condition is stated as a **rule in `SPEC-HUP-001`**, not only in this
repair's evidence, so an adoption performed by someone who never read this chain is still obliged to check.

As committed:

```text
**Rule 11 — approved work is startable afterwards.** Every work order in a state the adopted evaluator
treats as authority-granting, and which has not reached `implemented`, has its `start` checkpoint evaluated
by the adopted evaluator after the transaction. Every refusal is surfaced. A refusal arising from the
adoption itself is repaired, or the adoption is not complete.
```

It is also carried in that specification's own *Amendment record*, and `SPEC-HUP-001` is the artifact
`WO-HUP-001` named as its governing specification -- so the next adoption reaches it by following the same
reference the last one did.
