The same reading outside the suite: replay identity on both platforms
--------------------------------------------------------------------

The suite's own byte comparison is `the_live_transcript_replays_into_the_run_its_record_stream_describes`,
and it passes on both platforms above. It is re-taken here outside the suite, because the one fact this
work order's disclosures leave open is whether an engine output depends on the platform that produced it.

    Mokiterions --policy llm --seed 0 --ticks 50         --transcript-path docs/.../WO-MOK-026/live-run-transcript.jsonl         --events-path <scratch>/records.jsonl

  Windows, target/release/Mokiterions.exe    exit 0, standard error 0 bytes
  Linux,   target/debug/Mokiterions          exit 0, standard error 0 bytes

  rendered output       76,819 bytes on both
                        9563b4817a6696f0ce40af3bc6fd82cc0d57e80841182d3ad81beb14780a48bb on both,
                        which is the digest of the retained live-run-stdout.txt: the replay reproduces
                        the live run's own output byte for byte on each platform independently.

  record stream         157,153 bytes, 785 lines, 0 CRs on both
                        d0c281b3e60d10591be712d7ed9acae2b576fed1ce604af5934ca039efa71e4c on both

So every byte the engine produces from this transcript is platform-independent, and the debug and release
profiles agree as well, since the two readings were taken one of each.

This narrows the disclosure in live-run-measurements.md rather than contradicting it. That disclosure is
about live-run-record-stream.txt, 443 bytes and 2 lines, whose single CR is on line 1 --
`connector ready: model=gpt-5.6-luna endpoint=...` -- which the operator's connector wrote through
Python's text-mode standard error. Line 2, the engine's own run record, carries no CR. The retained
file's bytes therefore depend on the platform the *connector* ran on, and nothing in either Rust target
writes a CR. What is still unmeasured, and unmeasurable without paying for a third run, is whether a
live run on another platform would produce the same transcript; that is a statement about a provider and
a connector, not about this repository's code.
