# Test census: every test before the change and after it, reconciled name by name
#
# `VER-MOK-006` conformance check: "The workspace's test population is 169 before and 169 after:
# 60 in the engine and 109 in the observer. No test is added, removed, renamed, disabled or
# skipped. Every name is accounted for on both sides."
#
# Method. `cargo test -- --list` is not used, because it reports what a build produced and would
# report the same number for a test that had been silently rewritten. Instead each `#[test]`
# function is found by parsing the source, on both sides, and identified by the module it belongs
# to together with its own name. Before the change every observer test was
# `<module>::tests::<leaf>` or `verification::<leaf>` inside one binary; after it, a relocated
# test is a bare `<leaf>` in `tests/<module>.rs` whose file names its module, and a retained test
# keeps its in-crate path. Matching on `(module, leaf)` therefore follows a test across the move,
# and a name on one side only is a finding, not a rounding difference.
#

## Nothing is disabled or skipped

  No `#[ignore]` attribute exists anywhere in the workspace, and every one of the 17 test
  binaries reports `0 ignored` — `test-run.txt` carries the result line of each. A relocated
  test that had been quietly neutralised would still be counted by the census above, so this is
  a separate check and not a restatement of it.

  `verbatim-comparison.txt` closes the last gap: it compares each test's body, character for
  character, against the predecessor's. The census proves the names survived; that file proves
  the assertions did.
