# Public-item census: the interface the observer's library target exposes
#
# `VER-MOK-006` conformance check: "The observer's library target exposes the same interface its
# binary reached before, and no more: 97 public items across seven modules. A public field of a
# public struct and a variant of a public enum are parts of the item that declares them and are
# not counted again; there are 25 of them, so the same interface counted the other way is 122."
#
# Method. Each of the seven `pub mod` files is parsed outside every `#[cfg(test)]` block. A public
# item is a `pub const`, `pub static`, `pub fn`, `pub struct`, `pub enum`, `pub trait` or `pub type`
# declaration, including an inherent `pub fn` inside an `impl`. Public fields and enum variants are
# counted separately, because they are parts of an item already counted and not items in their own
# right. The predecessor's figures are not tabulated separately: `non-test-content.txt` establishes
# that all seven files are byte-identical outside their test blocks, so any census of one side is a
# census of both. The census is of the same seven files whether they are reached from `main.rs` by
# `mod` (predecessor) or from `lib.rs` by `pub mod` (candidate) — which is the point of the check.

  total             97             25             22

  97 public items — the recorded figure, exactly.
  97 + 25 = 122 — the recorded second figure, exactly, on a fields-only reading.

  No item is visibility-restricted: there is no `pub(crate)`, `pub(super)` or `pub(in ...)`
  declaration anywhere in the seven modules. Everything public is public to the binary, which is
  what makes the binary able to reach it through `use mokiterions_tui::...`.

# An adverse observation about the contract's own wording, recorded and not corrected
#
# The sentence quoted above says fields and variants "are parts of the item that declares them and
# are not counted again; there are 25 of them". Read as written, "them" names both fields and
# variants, and there are 25 + 22 = 47 of those, so the interface counted the other way would be
# 97 + 47 = 144. Read as fields only, both recorded figures — 25 and 122 — are exactly right, and
# 122 is independently corroborated by the count of `pub` occurrences in `non-test-content.txt`,
# which is also 122. The fields-only reading is therefore the one the author measured.
#
# This is an ambiguity in the wording of an approved contract, not an arithmetic error in it. The
# measured interface satisfies the check on the reading its own numbers came from. `VER-MOK-006`
# is approved, and amending an approved contract's pass condition is the assurance owner's act
# under `DECISION_RIGHTS.md`; it is not among the four amendments `ADR-MOK-004` enumerates. The
# contract is left as it stands and the observation is carried into the completion report and the
# verification record for the owner to dispose of.

# "and no more"
#
# The check's second half is negative: the library must not expose more than the binary reached.
# Nothing was made public to enable the relocation. The `pub` counts in `non-test-content.txt` are
# unchanged file by file, which is that claim measured: had a private item been published so that
# a relocated test could reach it, that file's count would have risen. `test-placement.md` shows
# the other side of the same fact — the 32 tests that stayed inline are exactly those that reach a
# private item or a `#[cfg(test)]` hook, and they stayed inline instead of the item being published.
