# The declared dependency sets, at the candidate

`WO-MOK-020` constraint 4: "The observer's declared dependency set is unchanged, and no
`Cargo.toml` gains an entry." The review preflight states the same obligation as a repository
command: "Each package's resolved dependency set must equal the set declared for it, at the declared
versions and feature sets ... `cargo tree -p Mokiterions -e normal --locked --offline` resolving to
one crate is what that comparison predicts today, because the engine's declared set is empty."
`SPEC-MOK-004` rule 14 records both commands and their required outcomes.

O19.1 asserts the engine half of this inside the suite, over the manifest text, in
`the_engine_declares_no_dependency_on_the_observer`. This file is the resolved-graph half: what
cargo actually resolves, which a manifest read cannot show.

ccb0584. `--locked` in every command in this packet means no run could have rewritten the lock file
