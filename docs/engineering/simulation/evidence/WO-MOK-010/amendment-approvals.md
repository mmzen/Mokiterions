branch must not have moved are compared against `60fda9f`, the commit this work started from. Artifacts it
must not have touched at all are compared against `7a2b502`, `master`'s tip, which this branch is merged

check would report `master`'s act as this work order's. What `master` changed is disclosed in §4 rather than
hidden by the choice of base. Every row this work order adds is dated `2026-08-19`.
