1. cargo fmt --all -- --check
------------------------------

    $ cargo fmt --all -- --check
    (no output)
    exit 0

Clean. The command prints a diff of what it would change and prints nothing when there is nothing, so
"no output" is the whole of the result and the exit code is the whole of the verdict.

Recorded honestly: this is not the first invocation. The first, against the change as first written,
reported three differences and exited 1 -- an `assert_eq!` that fitted one line by two characters too
few, a two-argument `assert_eq!` whose arguments rustfmt splits when a format string follows them, and a
five-link method chain rustfmt breaks one call per line. `cargo fmt --all` was run and the three were
taken as it wrote them. All three are in test code: two in
`mokiterions-core/src/simulation.rs`'s test module and one in `mokiterions-tui/src/state.rs`'s. The
result above is a re-check at this candidate, taken after the last of the test amendments, which rustfmt
left alone. **The engine text was not touched by the formatter**, which
post/world-rules-unchanged.txt measures independently: the module ahead of `#[cfg(test)]` is 3,055 lines
at this candidate and every changed line in it lies inside the three functions of the non-waste
condition. The line counts in post/test-census-reconciliation.md and post/updated-tests.md are the
formatted change's, not the first draft's.
