# Build and test — WO-MOK-005

The workspace first, then the engine package alone. The engine package alone is the check that
matters for `REQ-MOK-026`: it builds and its tests pass with the observer package excluded and
no terminal attached, which is what makes the engine independent rather than merely separate.

Re-captured on 2026-08-19 against the working tree that carries the amended rule 5, with both
packages cleaned first and no scratch measurement harness in the tree. Two things separate this
capture from the one it replaces, and only one of them belongs to this work order:

  * `WO-MOK-006` moved the engine package into `mokiterions-core/` and moved the observer's
    public tier into eight files under `mokiterions-tui/tests/`. The observer's tests therefore
    now run in ten binaries where the previous capture showed one, and every path below changed.
    No test was added or removed by that move: the observer's total was 109 before this work
    order touched it, exactly as the previous capture recorded.
  * This work order replaces the layout tier table with per-axis thresholds. That is the whole
    of the change in the counts: `tests/layout.rs` goes from 7 tests to 10, and the workspace
    total from 169 to 172. Two tests are gone —
    `tiers_match_the_specified_table_including_its_boundaries` and
    `tier_minimums_hold_wherever_the_tier_declares_one`, both of which asserted a table that no
    longer exists — one is renamed (`excluded_panes_are_the_ones_the_tier_omits` to
    `..._the_viewport_omits`), and five are new. `additivity-proof.txt` carries the per-file
    before-and-after that establishes the other 162 are the same tests rather than 162 different
    ones.

Both packages now split their suites across two tiers: the engine by `SPEC-MOK-002` rules 7 to 9
and the observer by `SPEC-MOK-004` rule 9. Every engine test below runs unmodified against the
engine sources this work order does not touch.
