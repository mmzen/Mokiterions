Every required verification case, its result and its evidence
============================================================

required list, with its result and the path to its evidence." The governing sentence of that
section is the one that shapes this file more than any other: "A case that cannot be run is
escalated, not omitted." Six rows below are therefore not green, one more passes and is escalated
anyway, one passes against a figure the artifacts state differently (L30), and one does not apply
at this stage. Each says why in the row rather than in a footnote a reader can miss.

Taken 2026-08-24 in the implementation tree on feature/phase-5-definition at commit bdaad99.

AMENDED at commit d002f04's successor, same day, in one place: L30's row said the ceiling is "set
to two exchanges", which is the case's figure and not the test's. The test uses eighteen and says
why. The correction is in the row, and candidate/per-tick-lending.txt is the capture that carries
the whole measurement. Nothing else in this file was re-measured, and no package file changed
between the two readings - bce4229 remains the last commit that did.
