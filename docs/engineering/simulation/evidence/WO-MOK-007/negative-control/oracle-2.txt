VER-MOK-007 oracle 2 - the shared entropy stream's position across trait derivation - negative control
=====================================================================================================

Acceptance scenario 3 requires that the entropy-position check be shown able to fail,
because a before-and-after comparison around a derivation that takes no stream would
otherwise be tautological.

Each perturbation below was applied to the committed source, the engine's own suite
was run, and the perturbation was reverted and the file checked byte for byte against
its digest. This artifact is generated by negative-control/controls.py from those
runs.

Perturbation applied
--------------------

  mokiterions-core/src/simulation.rs, Simulation::new, agent construction:

  -                waste_tolerance: derive_waste_tolerance(config.seed, number),
  +                waste_tolerance: derive_waste_tolerance(entropy.next_u64(), number),

This is the design `REQ-MOK-031` forbids: the derivation now takes its state from
the shared stream, so each of the twelve agents consumes one value from it.
